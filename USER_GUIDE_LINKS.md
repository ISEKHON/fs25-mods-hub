# 📋 User Guide: How to Submit Mods with Direct Links

## 🎯 Overview
Your FS25 Mods Hub uses an external link system - users provide direct links to their files and images instead of uploading to your server. This keeps costs low and gives users control over their content.

## 📦 Mod File Requirements

### ✅ **Supported Format**
- **Only .ZIP files allowed** (no .rar, .7z, or other formats)
- File should contain the mod folder structure
- Maximum recommended size: 500MB (depends on hosting service)

### 🔗 **Supported File Hosting Services**
- **Google Drive** (recommended for large files)
- **Dropbox** (good for sharing)
- **GitHub Releases** (perfect for open-source mods)
- **MEGA** (good for large files)
- **MediaFire** (popular choice)
- **Yandex Disk** (alternative option)

### 📝 **How to Get Direct Download Links**

#### **Google Drive:**
1. Upload your ZIP file to Google Drive
2. Right-click → "Get link"
3. Change permissions to "Anyone with the link can view"
4. Copy the link and modify it:
   - Original: `https://drive.google.com/file/d/FILE_ID/view?usp=sharing`
   - Direct: `https://drive.google.com/uc?export=download&id=FILE_ID`

#### **Dropbox:**
1. Upload ZIP file to Dropbox
2. Click "Share" → "Create link"
3. Copy the link and modify it:
   - Original: `https://dropbox.com/s/xyz/file.zip?dl=0`
   - Direct: `https://dropbox.com/s/xyz/file.zip?dl=1`

#### **GitHub Releases:**
1. Create a new release in your repository
2. Attach the ZIP file as a release asset
3. Copy the direct download link from the release page

#### **MediaFire:**
1. Upload ZIP file
2. Copy the direct download link provided

## 🖼️ Image Requirements

### ✅ **Required Images**
- **Thumbnail** (required): Main preview image for your mod
- **Screenshots** (optional): Up to 10 additional images

### 📏 **Image Specifications**
- **Formats**: JPG, PNG, GIF, WebP
- **Thumbnail**: Recommended 800x600px or 16:9 aspect ratio
- **Screenshots**: Any reasonable resolution (max 1920x1080 recommended)
- **File size**: Keep under 5MB per image for fast loading

### 🔗 **Supported Image Hosting Services**
- **Imgur** (recommended - free, no signup required)
- **PostImage** (free, reliable)
- **Google Drive** (if using public sharing)
- **Dropbox** (public links)
- **Discord CDN** (from Discord uploads)
- **GitHub** (for repository images)

### 📝 **How to Get Direct Image Links**

#### **Imgur (Recommended):**
1. Go to imgur.com
2. Upload your image (no account needed)
3. Copy the direct link: `https://i.imgur.com/xyz.jpg`

#### **PostImage:**
1. Go to postimg.cc
2. Upload your image
3. Copy the "Direct link" provided

#### **Google Drive (Images):**
1. Upload image to Google Drive
2. Right-click → "Get link" → "Anyone with link can view"
3. Get the file ID from the URL
4. Use format: `https://drive.google.com/uc?export=view&id=FILE_ID`

## 📋 **Submission Checklist**

### Before Submitting:
- [ ] ✅ ZIP file is properly formatted and tested
- [ ] 🔗 Download link works and points to ZIP file
- [ ] 🖼️ Thumbnail image displays correctly
- [ ] 📸 All screenshot links work
- [ ] 📝 Description is detailed and helpful
- [ ] 🏷️ Appropriate category selected
- [ ] ✅ All required fields completed

### Testing Your Links:
1. **Download Link**: Open in private/incognito window - should download ZIP
2. **Thumbnail**: Open link in browser - should display image
3. **Screenshots**: Check each link works and shows correct image

## ⚠️ **Common Issues & Solutions**

### **Download Link Issues:**
- ❌ "Link doesn't work" → Make sure it's a direct download link
- ❌ "Wrong format" → Ensure file is .ZIP format
- ❌ "Access denied" → Check sharing permissions are public

### **Image Link Issues:**
- ❌ "Image not showing" → Use direct image URL, not webpage URL
- ❌ "Wrong format" → Use JPG, PNG, GIF, or WebP only
- ❌ "Broken image" → Test link in private browser window

## 🎯 **Best Practices**

### **For Mod Authors:**
- Use descriptive filenames for your ZIP files
- Include README.txt inside ZIP with installation instructions
- Test your mod thoroughly before submitting
- Use high-quality screenshots to showcase features
- Keep file sizes reasonable for faster downloads

### **For Link Management:**
- Use reliable hosting services (Google Drive, Imgur recommended)
- Keep backup copies of your files
- Update links if you move files to different hosts
- Check your links periodically to ensure they still work

## 📞 **Support**

If you encounter issues with:
- **Link validation errors** → Double-check URL format and permissions
- **Upload problems** → Verify all required fields are completed
- **Technical issues** → Contact site administrators
